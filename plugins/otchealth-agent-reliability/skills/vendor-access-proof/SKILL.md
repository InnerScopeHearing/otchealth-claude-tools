# Vendor access proof

Resolve vendor, company connection, environment, own caller seat, exact target and required operation. Prefer matching direct vendor tools with verified company binding; use own-role gateway for identity, grounding and governed workflows.

Keep evidence separate:
| Level | Evidence |
| --- | --- |
| Read | Permitted bounded metadata read in exact client/company connection plus receipt. |
| Write | Approved synthetic/non-production target, pre-state, one controlled mutation, independently retrieved exact target/fields, and verified restore/cleanup when applicable. |
| Scoped Admin | Harmless authorized scoped operation or supported scope readback proving that specific administration ability. Catalog size and write success do not grant blanket admin proof. |

Discover actual callable names/schemas. Minimize technical acceptance fields; omit real customer/message/legal/financial source bodies. Save connection/receipt IDs without credential values. Route finance to CFO, corporate legal to CLO, operations to COO, revenue to CRO and app features to Developer.

Use one exact intent and writer. Use provider idempotency only if supported. Record permitted cleanup before mutation. Unknown outcomes freeze writing and cleanup until reconciliation.

Existing scope and provider consent still apply. For specifically authorized one-time cards choose Allow once, never Always allow. Do not bypass a rejection through another seat, credential or indirect call.

Return per-level PASS/FAIL/UNPROVEN, client/company/caller evidence, target and receipts, exact readback comparison, restoration state and missing gate. Another agent or deployment receipt is a handoff reference only.

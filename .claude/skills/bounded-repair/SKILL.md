# Bounded repair

Record one lane's baseline, primary measurable outcome, budget and acceptance before development. Seek at least 20 percent improvement where measurable; a missing capability uses a binary working test. Do not claim production improvement without measurements.

Make one focused diagnosis from actual error and execution context. Distinguish source defect, missing client binding, provider auth, sandbox/approval gate, stale semantic recall and service failure. Restricted-shell missing configuration is not proof of sign-out. Health alone is not a protocol handshake.

Allow at most two bounded repair attempts cumulatively across continuations. Use meaningful focused tests at the relevant helper/provider seam, including error projection and caller restrictions. Missing collections are not empty results; sanitized success does not prove sanitized errors.

Before mutation validate actual schema/bounds, one owner, pre-state, intent and rollback. Timeout or UNCONFIRMED is not safe-to-retry evidence. Freeze conflicting writes; reconcile exact status/result/evidence/contract or artifact verification. Only confirmed pre-dispatch rejection permits narrow request correction within remaining attempts.

Never route around auth, approval or security rejection, substitute identities/credentials, submit duplicate jobs, buy capacity or start paid fallback. Preserve best verified state.

At five-minute checks require a concrete milestone or authoritative live handle. Preserve original 10/20/30-minute stage cap. Running external jobs are not complete; interrupting an agent does not prove its job stopped.

When attempts exhaust or no credible gain fits budget, say Rule #1 in effect with baseline, evidence, reason and shortest viable alternative; continue independent authorized work.

Return changed state, exact evidence/tests, attempts, observable usage, unknowns, rollback state and dependency.

Synthetic case: write times out without receipt. Next action is read-only reconciliation, never a second write on a different route.

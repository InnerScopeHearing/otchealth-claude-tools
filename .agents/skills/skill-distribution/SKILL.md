# Skill distribution

Inventory installed metadata, callable tools and loader warnings before replacements. Filesystem presence, successful loader discovery and invocation differ. Compare company source-owned toolkit without copying protected or proprietary material.

Record baseline/outcome/budget/acceptance. Curate for demonstrated recurring work; reuse reviewed existing skills. Inspect third-party publisher, pinned revision, per-skill license, dependencies, hooks, scripts, network use and scopes before adopting. Do not execute unreviewed code or assume a blanket repository license.

Author original narrowly triggered SKILL.md with name/description frontmatter. Keep runtime details conditional. Skills do not create grants, memory engines, execution capacity or watchdogs.

Validate manifests/frontmatter/names/contained references/archive. Independently forward-test realistic synthetic cases and negative controls. Structural validation is not behavior acceptance. Preserve exact git commit and synchronize through supported source controls when exposed.

| Surface | Deployment and proof |
| --- | --- |
| ChatGPT/Work | Skills-only private plugin, release and exact source readback; separately prove installation/discovery/invocation. |
| Codex local | Supported plugin or repository .agents/skills in actual authorized runtime; prove discovery and invocation. |
| Codex cloud | Repository skills or supported cloud connection; prove exact environment/commit, own-seat load and harmless scenario. Laptop copies do not sync by assumption. |
| Claude | Own supported marketplace/plugin or .claude/skills; preserve per-skill licenses and verify runtime loading. |
| Hyperagent | Supported workspace skill import/agent attachment with readback. Thread APIs and import docs are not callable import proof. |

Enumerate seats/surfaces with version/hash. Track authored, validated, packaged, saved, published, installed, discoverable, invoked, accepted independently.

Use existing SWARM when parallelism helps; preserve global allocation/model/deadline rules. One owner integrates/publishes. Missing controls mean preserve package and report exact gate; no bypass helper.

Read [portable deployment](references/portable-deployment.md) when installing/exporting this pack.

For renewed Chat and Codex adoption, use [same-client acceptance](references/chat-codex-acceptance.md). Resolve the skill reader's exact package/resource identifier before declaring files missing; a cache path or short alias can differ from the supported resource surface. Check support files through that same reader. Preserve release-specific evidence when a publisher update has not reached an active loader.

# Capability preflight

Resolve one operation on one actual client. Installation, binding, authorization and execution are different observations.

Record the intended product, own seat, company connection, operation and runtime. Mark unobservable fields unknown. Project names, catalog entries and another agent's call are no identity proof. Use the matching own-seat startup and narrow Brain grounding once; use shared Brain separately for non-sensitive commons.

Inspect both the relevant skill catalog and callable tools. Some installed skills require an execution interface with no vendor-named tool. Read the selected skill's dependency before reporting the plugin absent. Compare source/provider catalog with this client's actual bindings. A handler without a binding is a client gap, not proof of provider failure.

Run the narrowest authorized harmless operation. Read, controlled write with exact readback, and scoped administration remain separate evidence levels. Work proof cannot accept ordinary Chat.

For ordinary Chat's missing or failing required direct tool, use the matching app's supported Settings Refresh once, then rerun the catalog in that same Chat. If this control is unavailable, report the dependency; do not substitute reconnect, another seat or indirect AWS. Respect auth, approval and sandbox rejections.

Local Edge requires this exact Chat's approved native tab bridge and harmless metadata. Cloud browsers, search and generic desktop availability do not pass it. Avoid enabling an already enabled plugin or launching a custom helper to replace an absent runtime binding.

Return client/seat evidence, installed-skill evidence, actual callable operation, dependency, correlation ID, highest proven capability and one next action.

Synthetic case: computer skill installed, documented execution interface absent. Report installed, execution blocked; name the interface. No extra grant or helper follows.
